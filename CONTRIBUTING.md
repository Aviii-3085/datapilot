# Contributing to Datapilot

Thank you for your interest in contributing to Datapilot.

Whether you're fixing a bug, improving documentation, suggesting a feature, or writing code, your contribution is appreciated.

## Before You Start

- Search existing issues before opening a new one.
- Discuss significant changes before starting implementation.
- Keep pull requests focused on a single feature or fix.

## Development Setup

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Datapilot.git
cd Datapilot
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it:

Windows

```bash
.venv\Scripts\activate
```

Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -e .
```

## Coding Guidelines

- Follow PEP 8.
- Write clear and descriptive code.
- Keep functions focused on a single responsibility.
- Add tests for new functionality whenever possible.
- Update documentation if behavior changes.

## Reporting Bugs

When reporting a bug, please include:

- Python version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior
- Error messages (if any)

## Feature Requests

Feature requests are welcome.

Please explain:

- The problem you're trying to solve
- Why it would benefit Datapilot
- A possible implementation, if applicable

## Pull Requests

Before submitting a pull request:

- Ensure tests pass.
- Run the formatter and linter.
- Keep commits meaningful.
- Write a clear description of your changes.

Thank you for helping improve Datapilot.
