# Datapilot Roadmap

This roadmap represents the planned evolution of Datapilot.

The roadmap is intentionally outcome-driven rather than feature-driven. Each release focuses on improving accessibility, developer experience, and analytical capability while maintaining a stable and intuitive API.

---

# v0.3 — First Public Release

## Goal

Deliver a stable and production-quality exploratory data analysis library suitable for public use.

### Objectives

- Stable analysis engine
- HTML reporting
- Professional report styling
- Dataset health scoring
- Statistical summaries
- Missing value analysis
- Duplicate detection
- Outlier detection
- Correlation analysis
- Insight generation
- Comprehensive testing
- Documentation

---

# v0.4 — Notebook Experience

## Goal

Make Datapilot feel native inside Jupyter notebooks.

### Planned Features

- Rich notebook rendering
- Inline report display
- Better developer experience
- Improved accessibility

---

# v0.5 — Interactive Analytics

## Goal

Transform static reports into interactive exploration.

### Planned Features

- Interactive charts
- Correlation heatmaps
- Distribution plots
- Better report navigation

---

# v0.6 — Export Engine

## Goal

Support professional sharing of reports.

### Planned Features

- PDF export
- PowerPoint export
- Improved HTML themes

---

# v0.7 — Extensibility

## Goal

Allow users to extend Datapilot.

### Planned Features

- Plugin architecture
- Custom analyses
- User-defined report sections

---

# v1.0 — Intelligent Data Analysis Platform

## Goal

Deliver a mature, extensible platform for understanding datasets.

### Long-Term Vision

- AI-assisted explanations
- Interactive dashboards
- Notebook-first experience
- Enterprise-ready architecture
- Stable public API
