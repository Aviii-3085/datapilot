# Code of Conduct

## Our Commitment

Datapilot is committed to creating a welcoming, respectful, and inclusive environment for everyone.

We encourage open discussion, constructive feedback, and collaboration.

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Welcome different viewpoints.
- Accept constructive criticism.
- Focus on improving the project.
- Help create a positive community.

## Unacceptable Behavior

Examples include:

- Harassment or personal attacks.
- Discrimination of any kind.
- Offensive language.
- Trolling or disruptive behavior.
- Publishing private information without permission.

## Enforcement

Project maintainers may edit, remove, or reject contributions that violate this code of conduct.

Repeated violations may result in temporary or permanent restrictions from participating in the project.

## Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Project documentation
- Community interactions related to Datapilot

## Contact

If you experience or witness behavior that violates this Code of Conduct, please contact the project maintainers through GitHub.
